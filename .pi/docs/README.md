# Blitz docs

Repo-local docs live under `.pi/` so product source stays clean.

- `product/` — durable product/architecture docs.
- `plans/current/` — active 0.5 implementation plans, prompts, and gates. Specs/PRDs/plans are one bucket here.
- `plans/archive/` — older 0.2/0.3/0.4/2.0 plans/specs kept for archaeology.
- `archive/` — old handoffs/spec snapshots.
